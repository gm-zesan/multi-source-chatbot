## 💡 How It Works

### Design System Flow
```
1. DESIGN TOKENS (_variables.scss)
   └─ Define colors, spacing, shadows, typography

2. REUSABLE MIXINS (_mixins.scss)
   └─ Create common patterns (flex-box, truncate, etc.)

3. COMPONENT STYLES (buttons, cards, forms, etc.)
   └─ Use tokens and mixins for consistency

4. MAIN STYLESHEET (style.scss)
   └─ Combines all files

5. HTML TEMPLATES (Blade files)
   └─ Apply semantic classes

6. AUTOMATIC INHERITANCE
   └─ New modules get design system automatically!
```

### Sidebar Toggle Flow
```
User clicks menu icon
    ↓
JavaScript event listener triggered
    ↓
Toggle .active class on sidebar
    ↓
CSS transition (300ms) animates width
    ↓
Sidebar expands/collapses smoothly
    ↓
Navigation labels appear/hide
    ↓
Content area shifts to accommodate
```

## 🎓 Usage Examples

### Using Design Tokens
```html
<!-- BEFORE: Hardcoded values -->
<div style="padding: 15px; margin-bottom: 20px; color: #333;">

<!-- AFTER: Design tokens -->
<div class="card">
    <!-- Automatically styled with:
         - $space-lg padding (16px)
         - $space-2xl margin (32px)
         - $text-primary color
         - $radius-lg border-radius
         - $shadow-card shadow
    -->
</div>
```

### Creating a New Page
```blade
<!-- No extra styling needed! -->
@extends('admin.app')

@section('content')
    <div class="card">
        <h1 class="page-title">My Page</h1>
        <p class="text-secondary">Description text</p>
        
        <!-- Buttons automatically styled -->
        <button class="btn btn-primary">Action</button>
    </div>
@endsection
```
